# CPI411

Sketchy Comic Non-Photorealistic Rendering Shader
Completed: 2026 | Duration: Prototype | Type: Graphics Programming / Shader

Sketchy Comic Non-Photorealistic Rendering Shader is a real-time graphics project developed in MonoGame using C# and HLSL .fx shaders. The project focuses on creating a stylized hand-drawn comic look instead of realistic rendering.

My main contribution focuses on implementing a shader pipeline that renders the 3D scene into a RenderTarget, extracts visual information such as edges and shading, and applies shader-based processing to create a sketchy non-photorealistic effect.

The effect uses GPU-based rendering techniques such as render-to-texture, edge detection, shade map processing, and HLSL pixel shader effects to produce comic-style outlines and stylized surface shading.
